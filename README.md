#  Docker Task Manager

A simple Task Manager application built using Node.js, Express.js, and MongoDB.

The application is containerized using Docker and managed with Docker Compose.

## Technologies Used
- Docker
- Docker Compose
- Node.js
- Express.js
- MongoDB
- HTML & CSS

## Features
- Add new tasks
- View tasks
- Delete tasks
- Store tasks in MongoDB
- Persistent data using Docker volumes

## Learning Outcomes
- Dockerfile creation
- Docker image building
- Multi-container applications
- Container networking
- Docker volumes
- Docker Compose
